# UML Diagrams
In this repository, all UML diagrams are written as PlantUML code. In order to render PlantUML in VS Code:
1. Go to Extensions
2. Search for "PlantUML" (by jebbs)
3. Install it 
4. (Additionally) install OpenJDK (if you don't hav it)
